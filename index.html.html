How it works
Five steps from complaint
to real-world resolution.
1
Citizen reports
Files verified issue with photo, GPS location, and description. Anonymous mode available.
2
AI classifies
Python FastAPI microservice categorizes the issue and routes to the correct department.
3
Community amplifies
Other citizens upvote and comment. High-vote issues trend publicly and reach journalists.
4
Official responds
Verified government officials respond publicly on record with action taken or ETA.
5
Citizens rate
Response quality rated on speed, quality, and satisfaction. Public scorecard updated.

Geo-tagged Issue Reporting
Citizens file verified issues with photo or video proof and auto-detected GPS location. Every complaint is pinned to a real place on the map — no vague descriptions, no unverifiable claims.
→
Auto GPS detection — location captured automatically, address resolved via reverse geocoding
→
Photo + video proof — media uploaded to AWS S3, compressed on device before upload
→
Department routing — AI reads the description and routes to PWD, MSEB, Municipal Corp automatically
→
Pincode + district tagging — every issue tagged for district-level heatmap aggregation
AI Issue Classification
A Python FastAPI microservice runs independently of the main Node.js API. Every submitted issue gets scored for category, sentiment, and spam probability — all in under 200ms.
→
10 categories: Roads, Power, Water, Sanitation, Police, Corruption, Education, Health, Environment, Other
→
94%+ accuracy — fine-tuned on Indian civic complaint language including Hindi-English code-switching
→
Async pipeline — AI runs after issue is saved, never blocks the submission API response
→
One pipeline, three features — AI scores feed moderation queue priority, trending algorithm, AND analytics heatmap simultaneously
Anonymous Whistleblower Reporting
Citizens can report corruption, police misconduct, or sensitive issues without revealing their identity publicly. Protection is built at the schema level — not just a UI toggle.
→
Schema-level separation — real reporter_id stored encrypted in DB, never returned in API responses when anonymous
→
Moderator-only access — only verified moderators with 2FA can see real identity for moderation purposes
→
Auto-delete — identity data auto-purged after 90 days if no moderation action taken
→
Per-post control — users set anonymous as default but can override per issue
Official Response & Ratings
Verified government officials respond publicly on record. Citizens rate every response on three axes. Public scorecards make ignoring complaints publicly embarrassing.
→
3-axis ratings — response speed (1-5), resolution quality (1-5), overall satisfaction (1-5)
→
Public scorecard — every official has a public page showing response rate, avg rating, and resolution time
→
Verification badge — officials verified by admin before they can respond publicly
→
"0 responses in 30 days" — unresponsive officials shown publicly, creating social pressure
District Issue Heatmaps
MongoDB's 2dsphere geo-indexing powers real-time heatmaps showing issue density by district. One index powers three features without duplication.
→
2dsphere index — MongoDB geospatial index enables $geoWithin and $geoNear queries at scale
→
Journalist portal — verified journalists get access to geo-filtered issue data exports for investigations
→
Government planning — district collectors see issue density maps to prioritize infrastructure spending
→
/issues/nearby API — geo-query endpoint returns issues within radius in <50ms response time
Real-time Notifications
Socket.io powers live updates so citizens never miss when their issue gets a response, reaches an upvote milestone, or gets resolved by officials.
→
6 notification types — status update, official response, upvote milestone, resolved, comment reply, moderation decision
→
Persistent storage — notifications stored in DB with is_read flag, never lost on disconnect
→
Push notifications — AWS SNS integration for mobile push notifications when app is backgrounded
→
Anonymous-safe — notifications sent without exposing reporter identity in anonymous mode
Trending Score Algorithm
A cron job runs every 30 minutes computing trending scores. High-priority issues surface to journalists and media automatically — no manual curation needed.
→
Formula: (upvotes×1.5 + comments×2) / hours^1.8 — naturally decays older issues
→
AI boost — high AI confidence score + urgent sentiment multiplies the trending score
→
Journalist feed — /issues/trending endpoint filtered by district for local media investigations
→
Anti-manipulation — vote velocity monitoring flags sudden artificial upvote spikes
Legal Awareness Module
Most citizens don't know their rights. SpeakUp India explains RTI, consumer protection, and labour law in plain language — integrated into every issue filing flow.
→
RTI filing assistant — guided step-by-step Right to Information filing tool (Phase 2)
→
Contextual cards — legal cards shown based on issue category. Road issue → show municipal corporation complaint rights
→
Legal aid connect — verified NGOs and legal aid organizations listed for citizens who need direct help
→
Plain language only — no legal PDFs. Answers like "what do I do if my landlord doesn't return my deposit?" in 60 seconds
